Import and export

Use the recipe toolbar actions to exchange individual recipes or bundles while keeping existing recipe identity intact.

Import recipes

Choose Import Template and select a .mntearecipe file for one recipe or a .mntearecipes file for a bundle. Review the import result notification and inspect the imported recipes in the browser.

When an imported recipe matches an existing recipe GUID, the importer updates that record. A new GUID creates a new recipe asset. Bundle import can include referenced item templates as dependencies.

Reimport from a recorded source

Reimport All refreshes existing recipes that have a recorded source file. It can include recipes hidden by the current search or browser filters. Unsaved recipe changes may prompt before source data replaces them.

Reimport uses each asset's recorded source; it does not create new recipes from unrelated files. Check the completion report for updated, skipped, or failed records.

Export recipes

Select one or more recipes and choose Export Item to write a single-recipe file or a bundle. Export serializes recipe identity, output, station requirement, timing, and ingredient rows. Referenced item templates can be included as bundled dependencies.

After moving files between projects, verify that the referenced item templates and required gameplay tags exist in the destination project.
