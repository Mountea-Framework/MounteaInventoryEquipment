Recipe setup

Build a recipe by choosing its output, adding each required ingredient, and setting any optional crafting requirements.

Set the output and timing

  1. Start a draft with New Template, or select an existing recipe in the browser.
  2. Set Result Item to the item template produced by crafting, then set Quantity Per Creation to the output count.
  3. Set Crafting Time to the duration used for the recipe.
  4. Optionally set Required Crafting Place to the gameplay tag for a required station. Leave it unset when no station is required.

Add ingredients

In Recipe Ingredients, add one entry for each item template the recipe requires. Set each entry's Ingredient Source and Required Quantity.

Every ingredient row is required. Add separate rows for separate inputs; there are no optional or “one of” groups in the current flat recipe model.

Review and save

  • Check that the result and every ingredient refer to the intended item templates.
  • Use Save Template for the current recipe or Save All Templates for all modified recipes.
  • Use Duplicate on a saved recipe to make a separate draft with a new GUID.
  • The crafting configuration's Allowed Recipes list controls which recipes are available to runtime crafting systems.
