Crafting Recipes Editor

Use this guide to understand the editor, build a recipe from item templates, and move recipe data between projects.

What a recipe describes

A recipe connects one result item to its required ingredients. It can also specify a crafting duration and an optional crafting station gameplay tag.

Recipe assets are grouped in the browser by the category of their result item. The browser search can match result names, station tags, categories, asset paths, and recipe GUIDs.

Editor layout

  • Toolbar: create, save, import, reimport, export, close, and open this tutorial.
  • Recipe browser: browse result-category groups, search recipes, and select one or several records.
  • Details: edit the selected recipe; with multiple recipes selected, edit their shared properties.

Start with a draft

The editor opens with a transient recipe draft. Fill it in and choose Save Template to create an asset. The saved recipe keeps its GUID when edited later. Use New Template to start another draft.

Continue with Recipe setup for the recipe fields and ingredient workflow, then Import and export for moving data.
